# Tour de Mini

A pixel-art sports minigame hub: a cycling sprint and descent, a 42.2-second marathon, and an
Ironman. Built with vanilla JavaScript and the Canvas 2D API, with no frameworks, game engines, or
build step.

Work in progress. The full README (how to run it, the architecture, how sprites are defined, and
how to add an athlete) arrives with the engine.

Athlete research notes: [docs/athlete-research.md](docs/athlete-research.md)
